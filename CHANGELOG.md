# Changelog

## 0.1.0 — 2026-08-23

- Added a guided CSV/XLSX profiling, preparation, outlier, visualization,
  training, evaluation, comparison, and inference workflow.
- Added CPU-only classification and regression catalogs across 14 algorithm
  families with leakage-safe validation and explainability diagnostics.
- Added six redistributable public datasets with discovery metadata,
  provenance, licenses, checksums, learning goals, and cautions.
- Added standalone Flask operation, a mountable `ml_server` blueprint, a
  responsive React interface, local Plotly assets, and configurable SVG/PNG
  chart export.
- Added backend, frontend, dataset, integration, packaging, CPU-policy, and
  browser-flow verification.
